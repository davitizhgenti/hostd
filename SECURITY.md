# Security

hostd's threat model (who can do what, on the network and on the machine, and how updates are protected) is in [docs/security.md](docs/security.md), also at https://davitizhgenti.github.io/hostd/security/.

## Reporting a vulnerability

Report it privately through GitHub: the repository's **Security** tab, **Report a vulnerability**. Please do not open a public issue. Fixes are released on the edge channel first; machines on it update by themselves within hours.
